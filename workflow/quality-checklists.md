# Quality checklists

Use these checks on generated content. Record results only when checks are actually run; do not prefill pass results.

## Source and coverage

- [ ] Source register has at least five distinct, reliable sources; Taiwan government and university sources are prioritized.
- [ ] Each source has enough bibliographic and location detail to retrieve the cited material.
- [ ] Each evidence card records source, original location, key information, Wiki section and level, limitations, and conflicting explanations.
- [ ] Coverage matrix checks all 30 section–level cells before lesson drafting; every cell has relevant evidence or the gate fails.
- [ ] Source differences are retained with context, not silently reconciled.
- [ ] A1–C1 are not presented as TOCFL equivalents without reliable supporting evidence.

## Content, language, and traceability

- [ ] Traditional Chinese is used. Run a Simplified-character detection/conversion check (for example, OpenCC) and manually review Taiwan usage; automated detection is not conclusive.
- [ ] Burmese explanation fields are present, display Myanmar script correctly, and are reviewed for meaning and naturalness.
- [ ] Zhuyin fields are present where required; verify symbols, syllables, and tones.
- [ ] Pinyin fields are present where required; verify spelling, tone notation, and conventions.
- [ ] Learning goals, examples, exercises, dialogues, quizzes, answer keys, and self-assessment are included as appropriate to the lesson.
- [ ] Factual claims cite source IDs and precise original locations; IDs resolve in the source register and evidence cards.
- [ ] Independent reviewer checks claims against original sources and evidence cards, not only the draft.

## Exercises and slides

- [ ] Fixed-answer exercises and quizzes have complete keys; check each key against its question.
- [ ] Open-ended items have an appropriate rubric or sample answer and receive human review.
- [ ] Slides trace to reviewed Wiki lessons; claims and examples retain citations or source links.
- [ ] Render HTML in a browser; check representative pages, navigation, layout, missing assets, and browser console errors.
- [ ] Confirm Traditional Chinese, Burmese, Zhuyin, and Pinyin render legibly in the HTML.
- [ ] Record actual findings and screenshots where useful; do not claim unrun checks passed.

## Correction-loop limits

- [ ] Track correction rounds separately for coverage, content/review, and slide rendering.
- [ ] Stop each loop after at most three correction rounds.
- [ ] If issues remain, report them and mark affected work unresolved or blocked.
